Contenido: Avance #3 Proyecto Estructuras de Datos
Resumen: Se presenta la entrega final del proyecto. El sistema consiste en el gestor de una tienda de guitarras y accesorios, donde usuarios pueden realizar la compra de productos en función de un inventario determinado. Finalmente se puede analizar cual es el camino más optimo para realizar la entrega en función de la distancia entre la tienda (San José) y la ubicación el cliente.

El proyecto implementa las siguientes estructuras de datos:
Lista enlazada simple: Para el carrito de los clientes.
Cola de prioridad: Para la atención de los clientes.
Arbol binario de búsqueda: Para el catálogo o inventario de la tienda.
Grafo ponderado y no dirigido: Para el mapeo de rutas y determinar entrega óptima.
